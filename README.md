# PadMouse 手柄鼠标

用 Xbox 手柄代替鼠标的 Windows 小工具。在托盘里安静运行，所有按键都可以改，也可以设成空键。

- 左摇杆移动鼠标，右摇杆滚动，A/B/X 是左/右/中键（按住 A 可拖拽）
- 按住扳机切换精准慢速 / 加速
- 托盘图标显示状态：绿色运行中，灰色已暂停，红色没有手柄
- 改键窗口：每个键可设为鼠标键、键盘按键或组合键、暂停、慢速/加速、屏幕键盘，或「无（空键）」
- 键盘按键在弹出的屏幕键盘上点选，Ctrl / Shift / Alt / Win 可多选组成组合键
- 按键一览：屏幕右下角透明背景的小窗，用图标标出每个手柄键对应的鼠标键或键盘按键；鼠标可点穿，不抢焦点
- 保存后立即生效，不用重启

支持 Xbox 手柄和切到 XInput 模式的第三方手柄。PS 手柄可先用 DS4Windows 或 Steam 转成 XInput。

## 下载

到 [Releases](../../releases) 下载 `PadMouse.zip`，解压后双击 `PadMouse` 文件夹里的 `PadMouse.exe`。不需要安装 Python。`_internal` 文件夹是程序的一部分，要和 `PadMouse.exe` 放在一起。

首次运行时 Windows 可能弹出 SmartScreen 提示，点「更多信息」→「仍要运行」。

启动后右下角会弹出「PadMouse 已启动」通知。Windows 11 默认把新托盘图标收在 **^** 里，可以把它拖到任务栏上常驻。

## 使用

| 操作 | 效果 |
| --- | --- |
| 左键单击托盘图标 | 暂停 / 恢复 |
| 右键托盘图标 →「按键一览」 | 在屏幕右下角显示 / 隐藏按键一览小窗 |
| 右键托盘图标 →「改键设置…」 | 打开改键窗口 |
| 右键托盘图标 →「退出」 | 退出 |

### 默认按键

| 手柄 | 功能 |
| --- | --- |
| 左摇杆 | 移动鼠标 |
| 右摇杆 | 滚轮（上下 / 左右） |
| A / B / X | 鼠标左键（按住可拖拽）/ 右键 / 中键 |
| Y | 屏幕键盘 |
| LT 按住 / RT 按住 | 精准慢速 / 加速 |
| LB / RB | 浏览器后退 / 前进 |
| 十字键 | 方向键（按住连发） |
| Back（两个方框） | Esc |
| Start（三条横线） | 暂停 / 恢复 |
| 按下左摇杆 / 右摇杆 | 任务视图（Win+Tab）/ 开始菜单（Win） |

### 改键

改键窗口的样式参考 Steam 输入：中间画着一个手柄，四周是分组卡片（扳机 / 肩键、摇杆、十字键、正面按键、菜单键），每一行显示一个键和它现在的功能。点卡片里的一行或手柄图上的按键选中它，在下面的编辑区改功能；选中摇杆时可以改摇杆模式和鼠标 / 滚动速度。

- 改键窗口在最前面时，手柄不控制鼠标键盘；按手柄上的键（或推动摇杆）会直接选中对应的那一行。
- 十字键可以整组设成「方向键」或「WASD」，这时只显示一行；选「分别设置四个方向」就分成四行，每个方向单独设置。
- 选键盘按键时，可以在弹出的键盘上点选，也可以直接按键盘上的键。改键窗口里会关掉中文输入法，避免按键被输入法吃掉。

每个键（包括 LT/RT）都可以选：

- **无（空键）**：按了什么都不做
- 鼠标左 / 右 / 中键，鼠标侧键（后退 / 前进）
- **键盘按键 / 组合键**：点「选择…」弹出一个屏幕键盘，直接点选；Ctrl / Shift / Alt / Win 可以多选，和其他键组成组合键，还有音量、播放、浏览器前进后退等按键。也可以直接输入，如 `ctrl+c`、`alt+tab`、`f5`、`win+d`；可勾选「按住连发」
- 暂停 / 恢复、精准慢速、加速、屏幕键盘、按键一览（显示/隐藏）、退出 PadMouse

左右摇杆可以设为移动鼠标、滚轮或无，鼠标速度和滚动速度也能调。

### 按键一览

右键托盘图标 →「按键一览」，屏幕右下角（任务栏上方）会出现一个透明背景的小窗：左边是手柄键图标（A/B/X/Y、肩键、扳机、十字键、摇杆），右边用鼠标图标或键帽标出对应的鼠标键、键盘按键。它总在最前面，但鼠标可以直接点穿它，也不会抢走焦点；改键保存后自动刷新。再点一次「按键一览」关闭，也可以给某个手柄键设「按键一览（显示/隐藏）」，用手柄直接开关。

在「改键设置…」的「按键一览」页里可以设置：

- PadMouse 启动时自动显示
- 不显示空键
- 显示哪些按键（可全选 / 全不选），右边有实时预览

设置保存在 `%LOCALAPPDATA%\PadMouse\config.json`，出问题时可查看 `%LOCALAPPDATA%\PadMouse\padmouse.log`。

## 从源码运行

需要 Windows 和 Python 3。

```bash
pip install -r requirements.txt
pythonw pad_mouse.py
```

其他命令：

```bash
pythonw pad_mouse.py --settings
```

```bash
pythonw pad_mouse.py --overlay
```

```bash
python pad_mouse.py --check
```

`--settings` 直接打开改键窗口，`--overlay` 打开按键一览小窗，`--check` 检测手柄是否连接。

## 打包

双击 `build.bat`，生成 `dist\PadMouse\`（`PadMouse.exe` 和 `_internal`）以及发布用的 `dist\PadMouse.zip`。
