PadMouse —— 用手柄代替鼠标
==========================

解压后双击文件夹里的 PadMouse.exe 即可运行，不需要安装 Python。
（_internal 文件夹是程序的一部分，要和 PadMouse.exe 放在一起。）
启动后右下角会弹出「PadMouse 已启动」通知，托盘出现手柄图标
（Windows 11 默认把新图标收在 ^ 里，可以把它拖到任务栏上常驻）：
  绿色 = 运行中    灰色 = 已暂停    红色 = 没检测到手柄
  左键单击图标 = 暂停/恢复
  右键图标 = 按键一览 / 改键设置… / 退出

支持 Xbox 手柄及 XInput 模式的第三方手柄。
PS 手柄需先用 DS4Windows 或 Steam 转成 XInput。

按键一览
--------
右键托盘图标 →「按键一览」，屏幕右下角会出现一个透明背景的小窗，
用图标标出每个手柄键对应的鼠标键或键盘按键。
它总在最前面，但鼠标可以直接点穿它，也不抢焦点；改键保存后自动刷新。
再点一次「按键一览」关闭；也可以在改键里给某个手柄键设「按键一览（显示/隐藏）」，用手柄直接开关。
在「改键设置…」的「按键一览」页里可以设置：启动时自动显示、不显示空键、显示哪些按键。

改键
----
右键托盘图标 →「改键设置…」。窗口中间画着手柄，四周是 Steam 输入那样的分组卡片，
点卡片里的一行或图上的按键选中它，在下面改功能（选中摇杆可以改摇杆模式和速度）。
改键窗口在最前面时，手柄不控制鼠标；按手柄上的键会直接选中它。
十字键可以整组设成「方向键」或「WASD」（只显示一行），也可以「分别设置四个方向」。
选键盘按键时可以在弹出的键盘上点，也可以直接按键盘上的键。
每个键（包括 LT/RT 扳机）都可以设成：
  无（空键）、鼠标左/右/中键、鼠标侧键（后退/前进）、
  键盘按键或组合键、暂停/恢复、精准慢速、加速、屏幕键盘、按键一览、退出 PadMouse。
键盘按键：点「选择…」会弹出一个键盘，直接点选；Ctrl / Shift / Alt / Win 可以多选，
和其他键组成组合键（例如 Ctrl + C、Win + D）。也可以在框里直接输入，如 ctrl+c。
键盘按键可勾选「按住连发」。左右摇杆可设为移动鼠标、滚轮或无。
点「保存」后立即生效；「恢复默认」回到下面的默认按键。
设置保存在 %LOCALAPPDATA%\PadMouse\config.json。

默认按键
--------
  左摇杆        移动鼠标
  右摇杆        滚轮（上下 / 左右）
  A / B / X     左键（按住可拖拽）/ 右键 / 中键
  Y             打开/关闭屏幕键盘
  LT 按住       精准慢速
  RT 按住       加速
  LB / RB       浏览器后退 / 前进
  十字键        方向键（按住连发）
  Back          Esc
  按下左摇杆    任务视图 (Win+Tab)
  按下右摇杆    开始菜单 (Win)
  Start         暂停 / 恢复（玩游戏前先暂停）
退出：右键托盘图标 →「退出」（也可以在改键里给某个键设「退出 PadMouse」）。

Back = Xbox 徽标左边「两个方框」的键（View）
Start = Xbox 徽标右边「三条横线」的键（Menu）

提示：首次运行时 Windows 可能弹出 SmartScreen 提示，
点「更多信息」→「仍要运行」即可。
出问题时可以查看日志：%LOCALAPPDATA%\PadMouse\padmouse.log
